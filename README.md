# Game Deals Radar

A learning project that will grow into a responsive web app for discovering discounted PC games.

## Project goal

Build a portfolio-ready application where users can:

- browse discounted games;
- search, sort, and filter offers;
- compare prices in PLN, UAH, EUR, and USD;
- save favourite games;
- use the interface comfortably on desktop and mobile.

## Roadmap

- [x] Semantic HTML structure
- [x] Responsive CSS layout
- [ ] JavaScript search, filters, and sorting
- [ ] External API integration and loading/error states
- [ ] TypeScript and React migration
- [ ] Accessibility, tests, performance, and deployment
